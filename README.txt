GFAlarm 3.0.8.1 Steam 版修复补丁

适用范围：已有 GFAlarm 3.0.8.1 的用户。本文件夹是覆盖补丁，不是完整程序。

安装方法：
1. 在原程序设置中关闭“自动更新”，保存设置后退出 GFAlarm。
   也可以在原程序的 Config.json 中把 "use_auto_update" 设为 false。
2. 将本文件夹内的 GFAlarm.exe 和 Resource 文件夹复制到原程序目录，选择覆盖同名文件。
3. 启动 GFAlarm，按原来的方式使用代理或模拟器。

请保留自己的 Config.json 和 Resource 中的其他文件。不要复制他人的证书或日志。

修复内容：Steam 中转域名、Steam 登录密钥获取、模拟器 Steam 登录及进入主界面所需的三个响应文件。
