GFAlarm 3.0.8.1 Steam 版修复补丁 0.3

[Fuwish注：本补丁全程使用AI（ChatGPT-6 Sol）生成，部分采用了本人及其他玩家研究成果，本补丁理应所做修改均列在本文件中。本人能正常使用，但不保证AI没有做其他修改，使用时请自行判断安全性。]

适用范围：已有 GFAlarm 3.0.8.1 的用户。本文件夹是覆盖补丁，不是完整程序。

安装方法：
1. 在原程序设置中关闭“自动更新”，保存设置后退出 GFAlarm。
   也可以在原程序的 Config.json 中把 "use_auto_update" 设为 false。
2. 将本文件夹内的 GFAlarm.exe、GFAlarm.MapOrderOverlay.dll 和 Resource 文件夹复制到原程序目录，选择覆盖同名文件。
3. 启动 GFAlarm，按原来的方式使用代理、模拟器和战役地图。

请保留自己的 Config.json 和 Resource 中的其他文件。不要复制他人的证书或日志。

0.3 地图功能：
- 地图右上角新增“点序图”开关。关闭时使用普通地图显示方式，开启时把路径点换成蓝色序号，并在连线两端标出该连接在各自 spot 的 route 列表中的顺序（从 1 开始）。路径点序号按 spot ID 升序排列，从 0 开始。
- 点序图保留敌人、建筑、梯队、支援等其他地图信息。某一端的 route 未列出该连接时，该端不标数字。
- “点序图”和“隐藏路径”是两个独立开关。隐藏点及相关路径仍只在“完整版”中显示。

沿用此前修复：Steam 中转域名、Steam 登录密钥获取、模拟器 Steam 登录及进入主界面所需的三个响应文件。
“隐藏路径”开关控制原版/完整版；完整版中连接隐藏点的路径向隐藏端渐变为半透明，两个隐藏点之间的路径整段半透明。
“噩梦迷城+”中，如果游戏数据将建筑 670115 或 670116 分配到点位 86399～86402 之一，地图会分别显示 2022WV02 或 2022WV04 图标。图标需要切换到“完整版”才能看到。
